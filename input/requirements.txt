Shady Meadows B&B (automationintesting.online) QA Requirements

============================================================
PART 1: USER INTERFACE (UI) REQUIREMENTS
============================================================

1. Homepage & Navigation
1.1 Verify that the homepage opens successfully at https://automationintesting.online/.
1.2 Verify that the webpage title is "Restful-booker-platform demo".
1.3 Verify that the hotel heading "Welcome to Shady Meadows B&B" is clearly visible.
1.4 Verify that navigation links are available: Rooms, Booking, Location, Contact, and Admin.
1.5 Verify that hotel contact information (address, phone, email) is displayed in the footer/contact section.

2. Room Listings & Booking Interface
2.1 Verify that the "Our Rooms" section displays available rooms with titles, images, amenities, and pricing.
2.2 Verify that each room card has a "Book now" button.
2.3 Verify that the "Check Availability" button is present and clickable.
2.4 Verify that clicking "Book now" on a room opens the booking/reservation interface with checkin and checkout options.

3. Contact Form ("Send Us a Message")
3.1 Verify that the contact form is visible with fields: Name, Email, Phone, Subject, and Message/Description.
3.2 Verify that submitting the contact form with valid input displays a success confirmation message.
3.3 Negative: Verify that submitting the contact form with empty fields displays appropriate validation errors.
3.4 Negative: Verify that submitting an invalid email format triggers a validation error message.
3.5 Negative: Verify that submitting a phone number with insufficient characters triggers a validation error message.

4. Admin Authentication & Login (/admin)
4.1 Verify that navigating to /admin displays the admin login form with Username and Password fields and a Login button.
4.2 Verify that an admin user can successfully log in using valid credentials stored in input/credentials.json.
4.3 Verify that successful login redirects the user to the admin dashboard at /admin/rooms.
4.4 Verify that an authenticated admin can see dashboard options such as Rooms, Messages, Branding, and Logout.
4.5 Negative: Verify that login fails when invalid username or password is provided.
4.6 Negative: Verify that login cannot be completed when username or password field is empty.
4.7 Verify that clicking the "Logout" button logs out the admin and returns to the login screen.


============================================================
PART 2: REST API REQUIREMENTS (Base URL: /api)
============================================================

5. Branding API
5.1 Verify that GET /api/branding returns HTTP status 200 OK.
5.2 Verify that the response JSON contains the hotel name "Shady Meadows B&B".
5.3 Verify that branding response contains map coordinates, description, and contact/address information.

6. Room API
6.1 Verify that GET /api/room returns HTTP status 200 OK.
6.2 Verify that the response JSON contains a list of rooms with roomName, type, accessible, and roomPrice.
6.3 Verify that GET /api/room/{id} with a valid room ID returns HTTP status 200 OK with the room details.
6.4 Negative: Verify that GET /api/room/{id} with a non-existent room ID (e.g. 999999) returns HTTP status 404 Not Found.

7. Authentication API
7.1 Verify that POST /api/auth/login with valid credentials in input/api_credentials.json returns HTTP status 200 OK.
7.2 Verify that the login response contains a valid "token" string.
7.3 Verify that POST /api/auth/validate with the generated token returns HTTP status 200 OK with {"valid": true}.
7.4 Negative: Verify that POST /api/auth/login with invalid credentials returns HTTP status 401 Unauthorized or 403 Forbidden.
7.5 Negative: Verify that POST /api/auth/login with empty/missing credentials returns an error status code (400 or 401).

8. Message & Contact API
8.1 Verify that POST /api/message with valid contact payload creates a message and returns HTTP status 200 or 201.
8.2 Verify that GET /api/message/count returns HTTP status 200 OK with a non-negative count property.
8.3 Negative: Verify that POST /api/message with missing mandatory fields returns HTTP status 400 Bad Request.

9. Booking API
9.1 Verify that GET /api/booking?roomid=1 returns HTTP status 200 OK with a list of bookings.
9.2 Verify that each booking entry contains bookingid, roomid, firstname, lastname, and bookingdates.
